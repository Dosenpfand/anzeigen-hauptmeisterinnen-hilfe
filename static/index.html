Nutzungsbedingungen

Wir speichern keine personenbezogenen Daten von dir direkt auf unseren Servern über den unmittelbaren Verarbeitungsvorgang hinaus.

Das von dir hochgeladene Foto wird zur Analyse (z.B. Kennzeichenerkennung) über OpenRouter, einen Dienst der OpenRouter, Inc. (USA), an Google Gemini, einen Dienst von Google, weitergeleitet und dort verarbeitet. Durch das Hochladen des Bildes und die Nutzung dieses Dienstes stimmst du dieser Verarbeitung zu.

Enthält das Foto Standortdaten (GPS), werden diese Koordinaten an Nominatim, einen Dienst der OpenStreetMap Foundation, übermittelt, um daraus eine Adresse zu ermitteln.

Wenn du die Option "Aktuellen Standort verwenden" aktivierst, fragt dein Browser nach deiner Erlaubnis und dein aktueller Standort wird beim Absenden an unseren Server übermittelt. Er wird nur verwendet, wenn das Foto keine Standortdaten enthält, und wird in diesem Fall ebenfalls an Nominatim übermittelt. Ohne diese Option wird dein aktueller Standort nicht abgefragt.

Bitte beachte die Datenschutzbestimmungen von OpenRouter, Google, Google Cloud und OpenStreetMap:

  • OpenRouter Datenschutzerklärung
  • Google Datenschutzerklärung
  • Google Cloud Datenschutzerklärung
  • OpenStreetMap Foundation Datenschutzerklärung

Durch Anklicken der Checkbox "Nutzungsbedingungen akzeptieren" bestätigst du, dass du diese Bedingungen zur Kenntnis genommen hast und akzeptierst.
